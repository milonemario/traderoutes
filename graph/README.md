# Data Sources

## Roads Network

The roads network is from the Natural Earth Data website.
It can be dowloaded here: [https://www.naturalearthdata.com/http//www.naturalearthdata.com/download/10m/cultural/ne_10m_roads.zip](https://www.naturalearthdata.com/http//www.naturalearthdata.com/download/10m/cultural/ne_10m_roads.zip)

## Cities

The worlds cities are a combination of:

- Countries main cities from CEPII.
- World cities are from [https://simplemaps.com/data/world-cities](https://simplemaps.com/data/world-cities).

## Ports

Ports information were extracted from World Port Source.

## Shipping Network

The shipping routes network is from the Oak Ridge National Labs CTA Transportation Network Group.
It is available to download at [http://geocommons.com/datasets?id=25](http://geocommons.com/datasets?id=25).
